Mastering Terminal Commands for LLM Enthusiasts

rev 0.1 · notes · ~3 min read

These commands give you almost complete control over any Unix-like terminal. Learn them once and you stop fighting the machine.

File System Navigation & Management

  • pwd — absolute path of the current directory
  • ls -la — all files including hidden, with permissions and sizes
  • cd <dir> — change directory (cd .. up, cd ~ home)
  • mkdir -p <path> — create folder + any missing parents
  • cp -r <src> <dst> — recursive copy
  • mv <src> <dst> — move or rename
  • rm -rf <path> — recursive force delete (respect it)

Viewing & Editing Files

  • cat <file> — dump entire file to stdout
  • less <file> — scrollable viewer (q to quit)
  • head -n 10 / tail -n 10 — first or last 10 lines
    tail -f streams live log updates
  • nano <file> — simple in-terminal editor

Text Processing & Searching

  • grep -rn "term" . — recursive search for a string in all files
  • find . -name "*.txt" — locate files by name pattern
  • wc -l <file> — count lines

System Operations & Networking

  • ps aux — every running process
  • kill -9 <PID> — force kill by process ID
  • df -h / du -sh <folder> — disk free space / folder size (human readable)
  • curl -I <url> — fetch HTTP headers only (connectivity / API smoke test)

Master these and the terminal stops being a barrier. It becomes the control plane.
